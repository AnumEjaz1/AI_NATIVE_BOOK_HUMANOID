# Introduction

Welcome to the AI Native Book on Humanoid Robotics. This comprehensive guide covers the essential concepts of Physical AI and humanoid robotics, from foundational principles to advanced implementation techniques.

## About This Book

This book is designed for advanced students, developers, and educators entering Physical AI and humanoid robotics with basic Python knowledge. Each module builds upon the previous one, creating a comprehensive understanding of humanoid robot systems.

## Modules

- **Module 1**: The Robotic Nervous System (ROS 2) - Learn about ROS 2 as the core middleware for humanoid robot control
- **Module 2**: The Digital Twin (Gazebo & Unity) - Explore physics simulation with Gazebo, high-fidelity interaction with Unity, and sensor simulation for perception
- **Module 3**: The AI-Robot Brain (NVIDIA Isaac™) - Master advanced perception, simulation, and navigation for humanoid robots using NVIDIA Isaac technologies, including Isaac Sim for synthetic data, Isaac ROS for accelerated perception, and Nav2 for humanoid navigation
