# Module 3 Glossary: The AI-Robot Brain (NVIDIA Isaac™)

## A

**Adaptive Monte Carlo Localization (AMCL)** - A probabilistic localization system that uses particle filters to estimate robot pose in a known map.

## D

**Domain Randomization** - A technique in synthetic data generation that involves varying the visual appearance of objects and environments during training to make models robust to different conditions.

**DNN Inference** - Deep Neural Network inference, the process of using a trained neural network to make predictions on new data.

## F

**Footstep Planning** - The process of generating sequences of foot positions that maintain balance for bipedal robots.

## I

**Isaac ROS** - NVIDIA's collection of hardware-accelerated perception and navigation packages designed specifically for robotics applications using ROS 2.

**Isaac Sim** - NVIDIA's simulation environment built on Omniverse that enables the creation of photorealistic virtual worlds for training AI models.

## N

**Nav2** - Navigation 2, ROS 2's navigation framework that provides localization, path planning, and navigation capabilities.

## S

**Simultaneous Localization and Mapping (SLAM)** - A process where a robot builds a map of an unknown environment while simultaneously keeping track of its location within that map.

**Synthetic Data Generation** - The process of creating artificial data that mimics real-world data for training machine learning models.

## V

**Visual SLAM (VSLAM)** - Visual Simultaneous Localization and Mapping, a type of SLAM that uses visual sensors (cameras) as the primary input for mapping and localization.

**Voxel Layer** - A 3D costmap layer in Nav2 that represents obstacles in a 3D grid format, useful for robots that need to consider height information.
